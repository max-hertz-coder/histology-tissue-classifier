# histology-tissue-classifier
Robust 9-class histology tissue classification using PyTorch &amp; EfficientNet-B0. Features HED color augmentations, domain-shift stress testing, an ensemble of 3 models, and Test-Time Augmentation (TTA).
# Практическое задание №1. Классификация гистологических изображений тканей

Многоклассовая классификация патчей гистологических препаратов на 9 классов тканей: ADI, BACK, DEB, LYM, MUC, MUS, NORM, STR, TUM. 

Основная метрика - balanced accuracy (классы сбалансированы в тесте, но может быть дисбаланс в скрытых данных, поэтому bacc надежнее). Дополнительно считаются accuracy, чувствительность и специфичность по каждому классу.

## 1. Разведочный анализ данных (EDA)

Перед обучением был проведён EDA, который повлиял на все дальнейшие решения:
- **Размеры датасетов:** `train` - 18000 картинок (по 2000 на класс), `test` - 4500 картинок (по 500 на класс). 
- **Средний цвет по классам:** ADI и MUC заметно светлее и бледнее остальных. Часть сигнала о классе содержится уже в цвете, но полагаться только на это опасно.
- **Сдвиг домена train <-> test:** цветовые средние и гистограммы яркости train и test почти идентичны. Однако при тестировании на скрытых наборах окраска и сжатие с высокой вероятностью другие. Это обосновало HED-джиттер и стресс-валидацию.
- **Яркостные выбросы:** в каждом классе есть тёмные (<30) и пересвеченные (>230) патчи - сеть не должна на них ломаться.
- **Визуализация:** построена сетка примеров по классам для проверки семантики.

## 2. Архитектура и обучение

- **Бэкбон:** `timm.create_model('efficientnet_b0', pretrained=True, num_classes=9)`. Transfer learning с ImageNet - критично из-за небольшого объема данных (в `train_tiny` всего 900 патчей).
- **Вход:** 224x224x3, нормализация ImageNet (`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`).
- **Loss:** `CrossEntropyLoss(label_smoothing=0.1)` - сглаживание меток из-за шума разметки и близких классов (STR <-> MUS).
- **Оптимизатор:** AdamW, `weight_decay=1e-2`.
- **Расписание:** OneCycleLR (`pct_start=0.2`).
- **Mixed precision** (`torch.amp.GradScaler`) + gradient clipping (1.0).
- **Батчи:** 64 train / 128 val и test.
- **Эпох:** 15 при полном прогоне.

Гиперпараметры:

| Параметр | Значение |
|---|---|
| EPOCHS | 15 |
| MAX_LR | 1e-3 |
| WEIGHT_DECAY | 1e-2 |
| LABEL_SMOOTHING | 0.1 |
| MIX_PROB | 0.5 |
| BATCH_SIZE | 64 / 128 |
| SEEDS | [42, 7, 2026] |

## 3. Аугментация

Аугментации подбирались под гистологию. Цель - заставить сеть учиться текстуре и структуре ткани, а не цвету, и повысить устойчивость к смене домена (другая лаборатория, другой сканер, другой протокол окрашивания).

Итоговая цепочка train_tf:

    T.Compose([
        T.RandomHorizontalFlip(p=0.5),
        T.RandomVerticalFlip(p=0.5),
        RandomRot90(),                                # 0/90/180/270
        HEDJitter(sigma=0.08, p=0.8),                 # джиттер красителей H/E/D
        T.ColorJitter(brightness=0.2, contrast=0.2,
                      saturation=0.1, hue=0.02),
        T.RandomApply([T.GaussianBlur(kernel_size=5,
                                      sigma=(0.1, 1.5))], p=0.2),
        T.ToTensor(),
        T.Normalize(IMAGENET_MEAN, IMAGENET_STD),
    ])

Обоснование по каждой аугментации:

| Аугментация | Зачем |
|---|---|
| Горизонтальное + вертикальное отражение | У ткани нет выделенного «верха»; отражения сохраняют семантику. |
| RandomRot90 (кратные 90 градусов) | Препарат снимается под разными углами, повороты на 90 градусов не создают пустых краёв. |
| HEDJitter (sigma=0.08, p=0.8) | Через `skimage.color.rgb2hed -> hed2rgb` случайно сдвигает концентрации гематоксилина/эозина/DAB. Самый реалистичный сдвиг домена в микроскопии. sigma увеличивал с меньших значений - сеть слишком цеплялась за окраску. |
| ColorJitter (слабый) | Микро-вариации яркости/контраста/насыщенности от сканера. Намеренно слабый, чтобы не уничтожить полезный цветовой сигнал. |
| GaussianBlur (p=0.2) | Нерезкие участки слайда (расфокус, тонкий срез). |

## 4. Валидация и стратегия выбора модели

- **Разбиение:** 85 / 15 train / val, стратифицировано по классам (`train_test_split(..., stratify=labels, random_state=42)`). В итоге 15300 train и 2700 val.
- **Роль валидации:** Первая модель ансамбля обучается с валидацией и по ней выбирается лучшая эпоха. Остальные модели учатся на всём `train` - берётся последняя эпоха. Валидация остаётся независимой от моделей 2 и 3.
- **Стресс-валидация:** Помимо чистой валидации, для каждой эпохи строятся 5 детерминированных искажённых копий:

    STRESS = {
        'hue':   TF.adjust_hue(im, 0.05),
        'gamma': TF.adjust_gamma(im, 1.4),
        'blur':  T.GaussianBlur(kernel_size=7, sigma=1.5),
        'jpeg':  jpeg_compress(im, quality=40),
        'hed':   HEDShift(alpha=[1.1, 0.9, 1.0], beta=[0.03, -0.03, 0.0]),
    }

**Критерий выбора лучшей эпохи:** `robust_score = 0.5 * bacc(clean) + 0.5 * mean(bacc по стресс-наборам)`

## 5. Инференс и тестирование

- **Test-Time Augmentation (TTA):** 8 видов = 2 (flip) x 4 (rot90). Усредняются вероятности (softmax)
- **Мониторинг во время обучения:** Каждую эпоху считается accuracy на стратифицированной подвыборке теста (90 картинок на класс).
- **Итоговые метрики:** accuracy, balanced accuracy, нормированная матрица ошибок (`plot_confusion`), чувствительность/специфичность по каждому классу (one-vs-rest), CSV предсказаний, визуализация ошибочных патчей (`show_errors`).

## 6. Ансамбль

- **3 модели** EfficientNet-B0 с разными seed: `[42, 7, 2026]`.
- **Софт-голосование:** усреднение softmax по всем моделям и всем TTA-видам, затем `argmax`:

    probs = 0
    for net in self.nets:
        for v in views:
            probs += torch.softmax(net(v).float(), dim=1)
    return probs.argmax(dim=1)

## 7. Инфраструктура обучения

Всё обучение построено так, чтобы его можно было прерывать и продолжать без потерь и чтобы все показатели фиксировались.
- **Автосохранение:** после каждой эпохи в `/content/drive/MyDrive/prak_nn_1/ckpt/m{member}/` пишутся `epoch_N.pt`, `best.pt` (лучшие по `robust_score`), `last.pt` (полный state для возобновления).
- **Возобновление после падения Colab:** `train(resume=True)` подхватывает `last.pt` и продолжает с той же эпохи.
- **Дообучение на новом наборе:** `finetune(dataset, epochs=2, max_lr=1e-4)`.
- **Логи и графики:** 4-панельный график (`training_curves.png`): train loss, train/val acc/bacc, bacc на чистой и стресс-валидации, LR по эпохам.
- **Автовыбор max_lr (`select_hparams`):** сетка `{3e-4, 1e-3, 3e-3}`, 2 эпохи на вариант на подвыборке по 500 картинок на класс, лучший - по `robust_score`.
- **Smoke-тест:** пайплайн проверяется на `train_tiny` (5 батчей, 1 эпоха) перед полным запуском.

## 8. Сохранение и загрузка

- `Model.save('best')` сохраняет весь ансамбль одним файлом: `{'arch', 'classes', 'state_dicts': [...]}` в `BASE_DIR`.
- `Model.load('best')`: если в `name_to_id_dict` задан `file_id` - качает через `gdown` (автозагрузка весов из облака); иначе читает локальный файл. Восстанавливает весь ансамбль через `build_net(pretrained=False)`.
- `Model.load_checkpoint(epoch, member=0)` - веса конкретной эпохи конкретной модели ансамбля.
- Корректность save/load проверена: после перезапуска среды и `load('best')` метрики на `test_tiny` совпадают с полученными до перезапуска.
